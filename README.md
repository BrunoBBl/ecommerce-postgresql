E-commerce PostgreSQL
📌 Sobre o projeto

Este projeto consiste na modelagem completa de um banco de dados relacional para um sistema de e-commerce utilizando PostgreSQL.

O objetivo principal foi praticar conceitos de SQL e modelagem de dados através da construção de uma estrutura próxima de sistemas reais utilizados no mercado.

O banco foi desenvolvido com foco em organização, integridade referencial, relacionamentos entre entidades e boas práticas de modelagem.

🚀 Tecnologias utilizadas
PostgreSQL
pgAdmin
SQL
